# Echo Vault

Source for `/play/echo-vault/`. Run the repository's `npm run serve`; its Eleventy passthrough rule publishes this page and app plus `games/_shared/` runtime files.

Twelve chambers share one seeded course. Patterns lengthen from three to nine tiles, playback speeds up, and later chambers add reverse recall and mirrored columns. Three lives last the entire run. One replay per chamber costs 100 points and restarts input. Wrong input stays at the current sequence position and costs 75 points and a life. No input timer.

Interrupted playback can be resumed, touch and number keys work, and sound is optional. Rules and privacy notes remain readable without JavaScript. See `games/README.md` for shared runtime and licence boundaries.
